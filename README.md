
# My Notes App

A simple and free notes application built using HTML, CSS, and JavaScript.

## Features
- Add new notes
- Edit existing notes
- Delete notes
- Search notes
- Automatically save notes in your browser

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## How to Use
1. Open the app.
2. Write a note title and content.
3. Click the Add Note button.
4. Your notes will be saved automatically.
